# T-1006 Acceptance Criteria

- [ ] AC1: A new hire following only the guide completes the day-one setup checklist without help.
- [ ] AC2: All 10 common ticket types have a step-by-step procedure with an expected result for each step.
- [ ] AC3: The escalation section names the criteria, the channel and the expected response time.
- [ ] AC4: The guide is 12 pages or fewer and uses consistent terminology with the ticket system.
- [ ] AC5: The support team lead has reviewed the guide and confirmed the content is accurate.
- [ ] AC6: The guide has been tested with at least one real new hire and the feedback is recorded.
