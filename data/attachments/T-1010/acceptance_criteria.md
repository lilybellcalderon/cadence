# T-1010 Acceptance Criteria

- [ ] AC1: All 240 labels appear in the crosswalk; none is silently dropped.
- [ ] AC2: Every mapped code is a valid ICD-10-CM code for the current code-set year.
- [ ] AC3: Every row has a confidence rating, and Low-confidence rows have a note explaining the ambiguity.
- [ ] AC4: Labels with no valid mapping or multiple plausible mappings are listed separately.
- [ ] AC5: The summary shows counts by confidence level.
- [ ] AC6: The requester can load the spreadsheet directly into the reporting system without reformatting.
